# Homelab

Kubernetes homelab focused on DevOps and Platform Engineering practices.

## Current stack

- Kubernetes: k3s
- GitOps: ArgoCD
- Configuration: Kustomize
- Secrets: SOPS + age + KSOPS
- Monitoring: Prometheus
- Dashboards: Grafana
- Alerting: Alertmanager
- Notifications: Discord
- CI: GitHub Actions
- Container registry: GHCR

## Goals

- Deepen Kubernetes knowledge through practical implementation
- Build a reproducible GitOps-managed cluster
- Practice observability, networking, storage, security, and resilience
- Keep the repository declarative
